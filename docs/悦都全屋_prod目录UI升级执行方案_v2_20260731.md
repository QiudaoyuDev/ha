## 0. 上次倒退的根因（已定位，源码级确认）

- `ExperienceLovelace/ha-floorplan` v1.x 是**重写版本**，配置模型为：`image:`(背景图) + `svg:`(叠加层) + `rules:`(实体→SVG 元素映射)。
- 它**不支持**旧版 pkozul floorplan-card 的 `<ha-state-icon>` 与 `on-tap` 写法（核对 `floorplan-card.js`：`ha-state-icon`=0、`on-tap`=0、`rules`=16、`image`/`svg`/`element` 均存在）。
- 上次写的 `yuedu-home.svg` 用了旧式标记 → 卡片整体渲染失败，连背景 2.5D 都不显示 → 用户感知"UI 倒退"。

## 1. 本版范围（多维度）

| 维度 | 内容 | 落地方式 |

## 2. floorplan-card 正确配置（v1.1.5 验证字段）

```yaml
type: custom:floorplan-card
image: /local/floorplan/yuedu-home-2p5d.png     # 2.5D 背景（卡片负责加载）
svg: /local/floorplan/yuedu-home-fp.svg          # 叠加层：5 个 <g id> 标记
rules:
  - entity: sensor.yue_du_kong_diao_zhan_shi_zhuang_tai
    element: fp-ac                                # 对应 SVG 中 id="fp-ac"
    tap_action: { action: navigate, navigation_path: '#yuedu-master-climate' }
    state_action:
      - state: "设备离线"
        class: "fp-off"                           # SVG <style> 中定义：灰化+降透明度
      - state_not: "设备离线"
        class: "fp-on"
  # ... 循环扇 fp-fan / 摄像机 fp-cam / 门锁 fp-lock / 洗衣机 fp-wash 同理
```

- `image:` 缺失会抛 "No image provided"；`svg:` 为叠加层；`rules[].element` 按 SVG 元素 `id` 匹配。
- 动作：`navigate`(带 `navigation_path`，跳 Bubble 弹窗) / `more-info` / `toggle` / `call-service` / `url`。
- 叠加层 `yuedu-home-fp.svg`：viewBox 1536×1024，5 个 `<g class="fp-marker" id=...>`（圆+emoji+`<title>`），`<style>` 定义 `.fp-on/.fp-off`。背景图不放在 SVG 内（改由 `image:` 提供），规避上次问题。

## 7. 执行中的两处调整（与上文方案不一致，特此更正）

1. **`state_action` 本轮未启用**：v1.1.5 的 `state_action` 字段格式在 JS 中无法确认（`state_not`/`fill`/`attribute`/`service` 计数均为 0），若写错可能导致卡片再次整体渲染失败（重演倒退）。**为安全，本轮 `rules` 只用 `entity`+`element`+`tap_action: navigate`**，保证 2.5D 必显示、标记必可点。离线灰化（`.fp-off`）等状态样式待你在浏览器实测、确认 `state_action` 格式后再补。
2. **kiosk-mode 下载失败（网络超时/404），墙屏为"内容常驻版"**：墙屏视图已实现大图 + 状态 chips + 快捷开关（摄像机电源/循环扇 `toggle`、空调点开弹窗）。隐藏 HA 头部/侧栏的 kiosk 效果未加——`kiosk-mode` 资源未下载成功，留作 HACS 可选安装（装好后在该视图首卡加 `type: custom:kiosk-mode` + `kiosk: true` 即可）。墙屏内容本身不依赖 kiosk，已可用。
