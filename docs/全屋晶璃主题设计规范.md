# 全屋晶璃主题设计规范

## 主题层级

- `全屋晶璃`：自动模式，Light 默认蓝紫灰，Dark 默认深蓝黑。
- `全屋晶璃 Light`、`全屋晶璃 Dark`：用于手动选择和排查明暗模式。
- `全屋晶璃 Lite`：保留半透明表面、边框和阴影，但不使用 `backdrop-filter`；墙屏优先使用。

标准版参考 `wessamlauf/homeassistant-frosted-glass-themes` 的 mode、`card-mod-card` 玻璃层、标题/Bubble 排除和 Lite 降级思路；颜色与背景均为本项目独立 Token。

## Token 约定

Dashboard 新样式只能使用 `crystal-*` 或 Home Assistant 语义变量：

`crystal-primary`、`crystal-accent`、`crystal-success`、`crystal-warning`、`crystal-error`、`crystal-offline`、`crystal-glass-bg`、`crystal-glass-border`、`crystal-glass-shadow`、`crystal-marker-bg`、`crystal-marker-border`、`crystal-marker-shadow`、`crystal-control-bg`、`crystal-popup-bg`、`crystal-video-bg`。

## 图像和嵌套规则

- 户型图 `/local/floorplan/yuedu-home-2p5d.png` 与摄像机画面不应用 Blur、透明度或色相滤镜。
- 外层卡可以使用玻璃；Bubble 外层、标题、Chips、Button Card 和内层实体卡不重复叠加玻璃。
- Select、Dialog 和菜单禁用模糊，避免下拉错位。
- Marker 只显示轻量边框/阴影和状态点，不将整颗 Marker 大面积染成成功或错误色。
