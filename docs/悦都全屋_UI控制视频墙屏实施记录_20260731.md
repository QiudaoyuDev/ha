# 悦都全屋 UI、控制、实时流与 iPad 墙屏实施记录

## 已落地

- 保留 `dashboard-v2.yaml` 作为手机/桌面主 Dashboard，新增 `dashboard-wall.yaml` 作为横屏墙屏 Dashboard。
- `configuration.yaml` 注册 `yuedu-wall`，并通过 `host.docker.internal` 为 HA 容器预留同机 go2rtc 访问路径。
- 新增 `悦都客厅实时流状态` 语义传感器：只有 `camera.yuedu_living_camera` 可用时才展示实时视频，否则显示离线安全态。
- 新增 `deploy/micam/.env.example`，真实账号、密码和 DID 只允许放在未跟踪的 `.env` 中。

## 米家实时流接入

1. 在 `deploy/micam` 复制 `.env.example` 为 `.env`，启动 `miloco go2rtc`。
2. 浏览器完成 Miloco 米家授权，取得 `chuangmi.camera.069a01` 的 DID；填写小写 MD5 密码和 `CAMERA_ID`。
3. 启动 `micam1`，宿主机用 VLC 或 go2rtc 页面验证 `rtsp://127.0.0.1:8554/yuedu_living_camera`。
4. HA 中添加 Generic Camera，实体命名为 `camera.yuedu_living_camera`，流地址使用上面的 RTSP 地址；确认实体可用后再启用墙屏实时卡。
5. 逐项验证首次播放、连续播放、停止/重播和米家离线回退。未完成真实流验证前，Dashboard 的离线占位是预期行为。

## iPad 墙屏交接

- 使用 Home Assistant Companion App 登录非管理员墙屏用户，打开 `悦都墙屏` Dashboard。
- 启用 iOS Kiosk Mode：横屏、隐藏侧栏、保持常亮、配置空闲屏保和定时刷新。
- 仅授予墙屏用户必要的客厅摄像机、空调、循环扇、洗衣机和场景控制权限；不授予门锁开锁、摄像机格式化、重启、维修权限。
