# Home Assistant 家庭智能家居 UI 设计与实施方案

## 项目背景

本项目基于 Home Assistant 构建家庭智能控制中心。

目标：

-   使用 iPhone 作为主要控制终端
-   支持 Siri / HomeKit 联动
-   构建高颜值家庭 UI
-   支持户型图可视化控制
-   支持未来持续增加智能设备
-   当前设备较少，但架构需要长期扩展

户型：

-   两室一厅一厨一卫
-   卧室A：主卧
-   卧室B：次卧
-   客厅：家庭核心区域
-   厨房
-   卫生间
-   阳台A

------------------------------------------------------------------------

# 一、整体设计理念

不要将所有设备堆积在一个页面。

采用：

    首页 Dashboard
        |
        +-- 家庭状态
        +-- 常用控制
        +-- 场景控制


    户型图 Dashboard
        |
        +-- 2.5D立体户型展示
        +-- 房间设备入口
        +-- 状态展示


    房间 Dashboard
        |
        +-- 客厅
        +-- 主卧
        +-- 厨房
        +-- 阳台

设计目标：

类似：

-   Apple Home
-   小米米家
-   高端智能家居中控

------------------------------------------------------------------------

用途：

主要UI组件。

负责：

-   空调
-   灯
-   风扇
-   锁
-   摄像头

-   阴影

    floorplan.png
