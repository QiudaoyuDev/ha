# 悦都全屋 Home Assistant Dashboard Review 与优化方案

## 一、分析对象

项目：

QiudaoyuDev/ha

当前目标：

-   基于 Home Assistant 原生 Lovelace 创建家庭智能中控
-   使用户型图作为家庭地图
-   支持空间化管理设备
-   支持未来扩展更多智能设备

当前已实现方向：

-   首页总览
-   家庭地图
-   客厅空间
-   主卧空间
-   阳台空间
-   未来空间预留

根据项目 README，目前采用：

-   原生 Lovelace
-   picture-elements 户型图
-   不依赖 HACS

该方向优点：

稳定、维护简单、迁移方便。

------------------------------------------------------------------------

# 二、当前架构评价

## 优点

### 1. 空间模型方向正确

当前没有把所有设备堆在首页。

采用：

    首页
     |
     +-- 家庭地图
     |
     +-- 客厅
     |
     +-- 主卧
     |
     +-- 阳台

这是正确的智能家居设计方式。

未来增加：

-   灯
-   窗帘
-   温湿度
-   人体传感器
-   扫地机器人

不会导致首页失控。

# 十、3D户型方案

当前 2.5D 户型路线正确。

不建议：

直接开发 Three.js 真3D。

原因：

-   维护成本高
-   移动端体验未必更好

推荐：

Sweet Home 3D / SketchUp

输出：

    2.5D 户型图
    +
    设备状态覆盖

------------------------------------------------------------------------
